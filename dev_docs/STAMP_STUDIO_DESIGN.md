# 印影スタジオ設計 v2

## 目的

印影を「既存フォントを丸や四角で囲むだけ」の機能ではなく、実寸の印鑑フォーマットを選び、文字を枠へ寄せながら仕上げられる編集画面にする。生成処理はPythonに置き、macOS / Windows / Linuxで同じSVGを生成する。

## 印影フォーマット

- 個人丸印
  - 9.5mm: ネーム印
  - 10.5mm: 標準
  - 12mm: 大きめ・フルネーム向け
  - 本文中の改行を保持し、横書きでは複数行、縦書きでは右から左の複数列として配置する。
- 会社認印
  - 18mm: 標準
  - 16.5mm: 小さめ
  - 会社名を外周へ、役職名を中央へ配置し、外枠と内枠を持つ。先頭文字の中心は真上に固定し、始終の切れ目はmm単位で調整する。中央役職は内円でクリップする。
- 会社角印
  - 21mm: 標準
  - 24mm: 大きめ
  - 会社名を改行可能な縦書き／横書きで配置し、外枠の角丸を0〜5mmで指定する。
- スタンプ
  - 13 x 27mm: 標準
  - 13 x 42mm: 大きめ
  - 横型／縦型、角丸、枠線（0で枠なし）、複数行へ対応する。可読性を優先し、線刻化は使わない。

仕上がりサイズはSVGの`viewBox`とは独立したメタデータとして扱う。PDFへ追加するときの初期サイズに使い、SVG自体は1000 x 1000の座標系で保存する。

## 文字モデル

- フォントのファミリーとフェイス（ウェイト／スタイル）を分けて選択する。
- OSフォントの`name`テーブルから日本語名を優先して取得し、見つからない場合は英語名へフォールバックする。
- 文字は最終的にすべてSVGパスへアウトライン化し、`text`要素を残さない。
- 個人丸印の本文、会社認印の中央役職、会社認印の外周会社名は、それぞれ文字ごとの編集状態を持つ。全体倍率と行間を先に適用し、その後で各文字をレイアウト後の中心を基準にX/Y移動と横/縦倍率で再調整する。改行は文字番号に含めない。
- 余白を小さくすることで枠へ寄せ、個別変形で各文字を枠へ接する位置まで調整できる。

## 線刻（篆書風の幾何表現）

フォント輪郭を低解像度の升目へ置き換える方式は廃止する。代わりに次の処理をPythonで行う。

1. アウトライン済みの各文字を、他の文字と混ぜずに長辺240px相当の一時的な二値画像へ描画する。
2. Zhang-Suen法で画線の中心まで細線化する。
3. 中心線画素を連結した線として追跡し、平滑化と簡略化を行う。
4. 緩い折れを三次ベジェ曲線で接続し、明確な角は残す。
5. 選択した線幅を持つ、塗りなしのSVGパスとして文字ごとに出力する。

この処理は元の字形に依存するため、本格的な印鑑用篆書字形そのものを自動設計する機能ではない。一方、従来のドット／升目表現ではなく、選んだフォントの骨格に沿った線ベースの表現になる。細部形状の安定性を保証するものではないため、補助的な表現としてプレビュー確認を前提にする。

## 枠外のクリップ

丸印は外円、会社角印は角丸四角形、会社認印は外周文字を外円・中央役職を内円の各中心線でクリップ境界にする。文字だけをクリップしてから、未クリップの枠線を最前面へ描画するため、文字は枠へ接触できるが外側へはみ出さず、枠線自体も欠けない。

SVGには標準の`clipPath`を保存する。PDF変換に使うMuPDFはSVGの`clipPath`を解釈しないため、アプリ内では外周文字・中央役職・枠を別レイヤーへ分け、SVGからPDFへ変換した直後に同じ円／角丸四角形のPDFクリッピングパスを各本文レイヤーへ焼き込む。

## API設計

印影設計は`format`, `sizeMm`, 本文または会社名／役職名、`fontId`, `direction`, `representation`, 枠・色・線幅・余白、全体文字用の倍率・行間・文字間、外周文字用の倍率・始終余白、中央文字用の`glyphTransforms`、外周会社名用の`companyGlyphTransforms`を持つ。スタンプでは長辺と向きも持つ。プレビューと保存は同じPython生成関数を使う。

生成済み印影のレスポンスには`defaultSizeMm`を含め、PDF編集画面で9.5mmへ固定せず、選択したフォーマットの実寸を初期値にする。

`embedMetadata`を指定したSVGは、文字情報を`metadata`タグへ保存する。レイアウト用の改行はメタデータと書き出しファイル名から除外する。押印画面でもメタデータ利用を指定した場合だけ、この文字情報を出力PDFのキーワードへ追加する。
