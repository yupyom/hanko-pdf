# Hanko PDF

PDFへ印影を配置し、実寸の印影SVGも作成できるローカルデスクトップアプリです。文書・印影・設定は外部サービスへ送信せず、すべてPC内で処理します。

ソースコード配布元: [yupyom/hanko-pdf](https://github.com/yupyom/hanko-pdf)

> Hanko PDFは、見た目のための押印ツールです。電子署名、証明書の付与、暗号化、タイムスタンプには対応しません。

## できること

- PDFを見ながら、PNG / JPG / WEBP / SVG / PDFの印影を配置
- 印影の位置、幅、高さ、角度をmm単位で調整
- 配置テンプレート、登録印影、一括書き出しを利用
- 個人丸印、会社認印、会社角印、長方形スタンプを実寸で作成
- OS上のフォントを選び、文字をアウトライン化したSVGとして保存
- SVG・PDF印影を、PDF内でもベクターのまま配置
- 任意で印影文字をSVGメタデータと出力PDFのキーワードへ保存

## macOS版のインストール

配布される `Hanko-PDF-macOS-*.dmg` を開き、`Hanko PDF.app` を `Applications` へドラッグしてから起動してください。DMG上のアプリを直接起動せず、Applicationsフォルダへコピーして使うことを推奨します。

配布DMGはDeveloper ID署名とApple公証を行ったものです。現在の配布ビルドはAppleシリコン（arm64）向けです。

## 使い方

1. 「PDFに押印」でPDFと印影を読み込み、紙面上で印影をドラッグして配置します。書類PDFは左側の選択枠だけでなく、右側のプレビューエリアへドロップしても読み込めます。
2. 左側の「位置とサイズ」で、位置・幅・高さ・角度をmm単位で微調整します。選択中の印影はDeleteまたはBackspaceキーでも削除できます。
3. 繰り返し使う配置はテンプレートとして保存し、複数の同じ帳票には一括処理を使います。
4. 「印影を作る」では、文字・書体・枠・色・余白を調整してSVG印影を作れます。
5. 「押印済みPDFを書き出す」で、元PDFを変更せず別ファイルとして保存します。

書類PDFを表示済みのときは、右側のプレビューエリアへ印影ファイルをドロップすることもできます。PNG / JPG / WEBP / SVG / PDF のうち、検出された幅・高さがともに50mm以下のファイルは印影として追加します。50mmを超えるPDFをドロップした場合は書類を差し替え、既に配置した印影は消去します。

### 印影を作る

| フォーマット | 仕上がりサイズ | 既定例 |
| --- | --- | --- |
| 個人丸印 | 9.5 / 10.5 / 12mm | 縦書き「猫田」 |
| 会社認印 | 16.5 / 18mm | 外周「・合同会社アメショ商会」 |
| 会社角印 | 21 / 24mm | 「合同会社／アメショ／商会之印」 |
| スタンプ | 13×27 / 13×42mm | 横型「超極秘」 |

文字の改行、全体・個別の文字倍率、行間、文字間、枠線・余白・色を調整できます。スタンプ以外では、補助的な表現として「中心線で線刻化」も選べます。線刻化はフォントによって仕上がりが大きく異なるため、必ずプレビューを確認してください。

## データとプライバシー

- PDF、印影、書き出し処理はローカルPC内だけで扱います。
- 設定・テンプレート・登録印影は、macOSでは `~/Library/Application Support/Hanko PDF/` に保存します。
- テンプレートは配置情報だけを保存し、PDFや印影そのものは保存しません。印影を明示的に登録した場合だけ、登録印影として同フォルダに複製を保存します。
- パスワード付きPDFは対象外です。

## 対応形式

- 押印対象: PDF
- 印影: PNG / JPG / WEBP / SVG / PDF
- SVG・PDF印影: 出力PDFでもベクター配置
- 画像印影: ラスター画像として配置

## 開発環境での起動

Python 3.12以降とmacOSのWebKit環境を想定しています。

```sh
./run.sh
```

初回起動時に、使用するPythonバージョン専用の仮想環境と必要な依存関係を準備します。開発起動ではブラウザから `http://127.0.0.1:8787` を開きます。
